# ✅ Focus Timer - Quick Start Guide\n\n**5 Minutes to Get Started**\n\n---\n\n## 🚀 Step 1: Import the Fresh Screen\n\nIn your main app file or router:\n\n```dart\nimport 'package:safe/features/focus_timer/presentation/screens/focus_timer_fresh.dart';\n```\n\n---\n\n## 🚀 Step 2: Add to Navigation\n\n**Option A: Add to Bottom Navigation**\n```dart\nNavigationDestination(\n  label: 'Focus',\n  icon: Icon(Icons.timer),\n  onPressed: () => Navigator.pushNamed(context, '/focus'),\n),\n```\n\n**Option B: Add to Router**\n```dart\nRoute(\n  path: '/focus',\n  builder: (context, state) => const FreshFocusTimerScreen(),\n),\n```\n\n---\n\n## ✅ Step 3: Verify Backend Endpoints\n\nCheck your backend has these endpoints:\n\n```bash\n# Create session\nPOST /api/v1/focus\nBody: { sessionType: \"25min\", duration: 25 }\n\n# Get active session\nGET /api/v1/focus/active\n\n# Pause session\nPOST /api/v1/focus/{sessionId}/pause\n\n# Resume session  \nPOST /api/v1/focus/{sessionId}/resume\n\n# Stop session\nPOST /api/v1/focus/{sessionId}/stop\n\n# Get daily stats\nGET /api/v1/focus/stats/today\n```\n\nIf any endpoint is missing, backend needs to implement them.\n\n---\n\n## 🎮 Step 4: Test It Out\n\n### Test 1: Start Session\n1. Open app\n2. Go to Focus Timer\n3. Click \"25 Minutes\"\n4. ✅ Timer should appear and start counting down\n\n### Test 2: Pause Session\n1. Timer is running\n2. Click \"Pause\"\n3. ✅ Timer should stop\n4. ✅ Button should change to \"Resume\"\n\n### Test 3: Resume Session\n1. Timer is paused\n2. Click \"Resume\"\n3. ✅ Timer should continue\n4. ✅ Button should change back to \"Pause\"\n\n### Test 4: Stop Session\n1. Timer is running or paused\n2. Click \"Stop\"\n3. ✅ Confirmation dialog should appear\n4. Click \"Stop\" again\n5. ✅ Session should end\n6. ✅ Screen should show \"Start a Focus Session\" again\n\n---\n\n## 📊 What You'll See\n\n### No Active Session\n```\n┌──────────────────────────┐\n│   Start a Focus Session  │\n│                          │\n│  [📱 25 Minutes      ]  │\n│  [🎯 50 Minutes      ]  │\n│  [⚙️ Custom Duration  ]  │\n│                          │\n│  Today's Stats:          │\n│  🎯 Sessions: 3          │\n│  ⏱️ Minutes: 75          │\n│  ⭐ XP: 150              │\n└──────────────────────────┘\n```\n\n### Active Session\n```\n┌──────────────────────────┐\n│     🔥 Active            │\n│                          │\n│         23:15            │\n│                          │\n│  [████████░░░░░] 65%     │\n│                          │\n│  [⏸️ Pause] [⏹️ Stop]  │\n│                          │\n│  Today's Stats: ...      │\n└──────────────────────────┘\n```\n\n---\n\n## 🔧 Features Available\n\n✅ **Start** - 25min, 50min, or custom duration  \n✅ **Pause** - Pause without losing progress  \n✅ **Resume** - Continue from where you paused  \n✅ **Stop** - End session with confirmation  \n✅ **Timer** - Real-time countdown  \n✅ **Progress** - Visual progress bar  \n✅ **Stats** - Today's focus statistics  \n✅ **Responsive** - Works on all devices  \n\n---\n\n## 📝 Logs to Monitor\n\nOpen Flutter console and look for:\n\n```\n🎯 Fresh Focus Timer Screen initialized\n🚀 Starting session: 25min for 25 minutes\n✅ Session started successfully\n⏸️ Pausing session: ...\n✅ Session paused\n```\n\nIf you see errors:\n```\n❌ Error starting session: ...\n❌ Error: Network error\n❌ Error: 404 endpoint not found\n```\n\nCheck backend logs and verify endpoints exist.\n\n---\n\n## ❓ Common Issues\n\n**Q: Timer doesn't update?**  \nA: Make sure you're using `FreshFocusTimerScreen` not the old one\n\n**Q: Pause button is disabled?**  \nA: Check backend endpoint `/focus/{id}/pause` exists\n\n**Q: Session doesn't start?**  \nA: Check:\n  1.
