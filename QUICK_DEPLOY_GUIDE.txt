║           FitFlow Gym - Quick Deployment Guide (< 1 hour)                 ║
╚════════════════════════════════════════════════════════════════════════════╝

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 STEP 1: MONGODB ATLAS (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://www.mongodb.com/cloud/atlas
2. Sign up or log in
3. Click "Create a Cluster"
4. Select M0 (Free)
5. Choose region
6. Wait for cluster to deploy (2-3 min)
7. Go to "Database Access" → "Add New User"
   Username: fitflow_admin
   Password: Auto-generate (copy it!)
8. Go to "Network Access" → "Add IP Address"
   Allow 0.0.0.0/0 (Allow Access from Anywhere)
9. Go to "Database" → "Connect" → "Connect your application"
   Copy connection string
   Replace <username> and <password>

✅ Copy this connection string:
   mongodb+srv://fitflow_admin:YOUR_PASSWORD@cluster0.mongodb.net/fitflow_gym

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📦 STEP 2: BACKEND SETUP (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. In backend folder, create .env file:

   NODE_ENV=production
   PORT=10000
   MONGODB_URI=mongodb+srv://fitflow_admin:YOUR_PASSWORD@cluster0.mongodb.net/fitflow_gym
   JWT_SECRET=your-secret-key-here
   JWT_EXPIRE=7d
   CORS_ORIGIN=*

2. Update server.js to use environment variables
3. Test locally:
   npm install
   npm start
   ✅ Should show: "✅ MongoDB connected"

4. Push to GitHub:
   git add .
   git commit -m "Ready for deployment"
   git push origin main

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 STEP 3: RENDER.COM DEPLOYMENT (10 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://render.com
2. Sign up with GitHub
3. Click "New +" → "Web Service"
4. Select your fitflow-backend repository
5. Configure:
   Name: fitflow-backend
   Environment: Node
   Build Command: npm install
   Start Command: npm start
6. Add Environment Variables:
   MONGODB_URI=mongodb+srv://fitflow_admin:PASSWORD@cluster0.mongodb.net/fitflow_gym
   JWT_SECRET=your-secret-key
   JWT_EXPIRE=7d
   CORS_ORIGIN=*
   NODE_ENV=production
7. Click "Create Web Service"
8. Wait for deployment (2-5 min)
9. Copy your Render.com URL (like: https://fitflow-backend-xxxx.onrender.com)

✅ Check logs: Should show "✅ MongoDB connected"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📱 STEP 4: UPDATE FLUTTER APP (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open: lib/core/network/api_endpoints.dart
2. Find line:
   static const String baseUrl = 'http://localhost:5000/api/v1';
3. Replace with:
   static const String baseUrl = 'https://fitflow-backend-xxxx.onrender.com/api/v1';
   (Use your actual Render.com URL without /api/v1 in the URL)
4. Save file
5. Rebuild app:
   flutter clean
   flutter pub get
   flutter run

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ STEP 5: TEST PRODUCTION (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. On device, open app
2. Test login
3. Create new habit
4. Create community post with image
5. Check analytics
6. Update profile photo
7. Check timer works

✅ If all works → Deployment successful!

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If MongoDB doesn't connect:
  → Check MongoDB URI (username, password, database name)
  → Check IP whitelist is 0.0.0.0/0
  → Wait a few minutes after creating cluster

If Render.com deployment fails:
  → Check Build Command: npm install
  → Check Start Command: npm start
  → Check .env variables are set
  → Check package.json has "start" script

If app can't connect:
  → Update api_endpoints.dart with correct URL (check it 3 times!)
  → Make sure URL is https:// (not http://)
  → Run: flutter clean && flutter pub get
  → Rebuild app
